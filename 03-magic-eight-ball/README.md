# Magic Eight Ball

This project is a JavaScript utility that acts as a digital Magic Eight Ball. It utilizes control flow to simulate a fortune-telling experience by providing random answers to user questions.

## Logic and Control Flow

The core logic relies on generating random outputs:
1. The program accepts a question from the user.
2. A random number generator is used to select a predefined fortune.
3. Control flow statements (`switch` or `if/else if/else`) evaluate the random number and output the corresponding Magic Eight Ball phrase (e.g., "It is certain", "Reply hazy try again", "Don't count on it").

## How to Run

1. Ensure you have [Node.js](https://nodejs.org/) installed on your system.
2. Clone this repository or download the source code into a file named `app.js`.
3. Open your terminal and navigate to the project directory.
4. Run the script using the following command:
   ```bash
   node app.js
